TRAINING SUMMARY - verify against the official source.

The FDA expects premarket submissions for "cyber devices" (devices that include software and can connect to the internet or to other systems) to show that cybersecurity was designed in from the start. Submissions are expected to include a threat model, a security architecture description, a software bill of materials listing the third-party components in the device, evidence of security testing, and a plan for monitoring, identifying and addressing vulnerabilities after the device is on the market.

The FDA also expects manufacturers to be able to update and patch devices in a reasonable time, and to have a coordinated vulnerability disclosure process so that researchers and customers can report problems.

What this means for a company: first decide which products are cyber devices. For each of them, check that the design history file contains the expected security documentation, that the software bill of materials is current, and that there is a written post-market plan for vulnerability handling. Significant changes to existing connected devices may also trigger these expectations, so change control procedures should ask the cybersecurity question explicitly.
